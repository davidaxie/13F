Concept A · Equity Curve

Berkshire · $10k mirrored · 2020 → 2025

Start with $10k on day one. Every 13F filing, rebalance your portfolio to match the fund's reported holdings. Track your account value daily using real prices. Overlay $10k put in SPY as a benchmark.

Strengths

  • Single intuitive number: "what would $10k be today?"
  • Apples-to-apples vs SPY, with real drawdowns
  • Captures the manager's full portfolio activity, not just new picks

Trade-offs

  • Heaviest to compute — needs every CUSIP's daily prices
  • Mostly tracks market beta; manager skill shows up as a slow divergence
  • Doesn't surface which specific picks drove the outperformance

Concept B · Cumulative P&L of completed trades

Berkshire · realized P&L on closed positions

Each "trade" is one position opened in a filing and closed in a later filing. When the fund exits, the trade is realized: entry price vs. exit price × position size = profit/loss. Plot the running total over time. Like a trader's P&L curve.

Strengths

  • Each "trade" is a discrete event you can name — Apple closed +18%, Tesla closed −12%
  • Naturally surfaces big winners and losers as labeled steps
  • Hit-rate & average-per-trade are interpretable

Trade-offs

  • Ignores still-open positions (Apple has been held for years — not in this chart)
  • Needs a clear "exit" definition — when shares drop to zero, or just reduced?
  • Cumulative $ depends on a position-sizing rule (equal-weight? mirror weight?)

Concept C · Trade scatter / hit-rate

Berkshire · every new position 2020 → 2025

Every new position opens one dot. X is entry date (when first reported). Y is total return — at exit if closed, marked-to-market if still held. Size of dot scales with position size at entry. Color: above zero is green, below is red.

Strengths

  • Visually shows manager skill — clustered above zero = picks winners
  • Outliers (the home runs) jump off the page
  • Hover any dot to see ticker / entry size / return — fits a research workflow

Trade-offs

  • No "what would I have made" — just per-pick performance
  • Doesn't reward big winners more than small ones (only bubble size hints)
  • Doesn't compare to SPY in a way that's intuitive
